# 4. D.1 — why EEx discovery is blocked

Job 26323892. The four known EEx put through the same 2014 specificity statistics
as 55 known machine profiles, before building anything.

```
statistic     EEx median (range)        machine median (range)
f_own         93.72 ( 0.00- 98.44)      92.22 ( 0.11- 98.92)   IDENTICAL
f_other        0.00 ( 0.00-  0.99)       0.83 ( 0.00- 73.08)
f_none         6.21 ( 0.57-100.00)       7.69 ( 0.29- 38.11)
pos_entropy    2.01 ( 0.00-  3.71)       3.31 ( 0.97-  4.95)
occupancy     14.01 ( 0.04- 88.26)      92.66 ( 4.65- 99.41)   best, overlapping
div_ratio     VOID -- ungapped-identity bug, see below
```

**`f_own` is flat.** The criterion the 2014 method rests on keeps EEx and machine
components equally.

**No occupancy cut works:**

```
occupancy < 20%   EEx 3/6 kept   machine 4/55 also   57% contamination
occupancy < 40%   EEx 4/6        machine 7/55        64%
occupancy < 90%   EEx 6/6        machine 23/55       79%
```

**And the machine criterion keeps ExcA** (`f_own>80 AND occupancy>80`), so
"subtract the machine, keep the residue" would discard a known EEx.

**What D.1 DID clear:** the same criterion recovers `traN` (f_own 92.2, occ 96.2)
and `traK` (95.7, 97.9) — the genes that were contaminating our MPF_F slots. The
annotation-repair half has a working criterion and a passing control.

## Two axes never actually tested

* **`div_ratio` is void.** `pid()` compares ungapped over small offsets — fine for
  near-identical copies, noise for real homologs. VirB4 scored 13.6% within-class
  identity when it should be 40–60%. The one axis designed to detect diversifying
  selection was never measured.
* **`pos_entropy` is n-confounded.** A family with 12 hits cannot exceed
  log2(12)=3.58 bits, so the 2.01-vs-3.31 gap partly reflects EEx families being
  smaller.

Both need fixing before the EEx question is closed inside this framework.

# 5. Methods tried and abandoned

| method | outcome |
|---|---|
| prevalence ranking of conserved short proteins | **wrong ordering term.** TrbK ranks 3,591 by prevalence in MPF_T; EEx are hypervariable, not conserved |
| covariation with partner allele (MI) | **threshold-dependent.** Passes at 50/70% id, fails at 90%; verdict is about mmseqs, not biology |

# 6. Known defects, unfixed

* **Slot fragmentation** — pair-keying splits one position across several slot IDs
  (MPF_T's Eex_IncN occupies 8, six flanking virB6). Fix: key by the VirB6
  homologue. Not implemented.
* **`MAXGAP = 3` uncalibrated** — carried over from a display rule. All four known
  EEx happen to sit in gaps of 1–3, which is a post-hoc observation on n=4.
* **Search window far narrower than 2014's** — we use gaps ≤3 between recognised
  genes; they used ±20 genes around VirB4. Anything past the last recognised gene
  is invisible to us.
* **Blindness is partial** — the slot RANKING is blind; the slot CONSTRUCTION was
  written knowing where the four EEx sit. Will not transfer to G/B/C.
* **`PrgA_Sea1` has no GA cutoff** — scanned at E≤1e-5 by precedent.
* **MPF_FA / MPF_FATA still one file** — 2,391 plasmids, 726 unassigned.
* **Prototype mismatch** — 2014's MPF_FA model is Tn916 (we used ICEBs1) and its
  MPF_G model is ICEHin10810 (we used ICEHin1056). Unchecked whether these are the
  same elements.
